# AI Trends Report - August 2026

## Ключевые тренды (Август 2026)

### 1. Open-Weight модели — обновлённая ситуация

**Kimi K3** (Moonshot AI) — крупнейшая open-weight модель на июль 2026:
- Лидирует в Frontend Code Arena, 76.8% на SWE-Bench Verified
- Самый сильный open-модель для кодинга на август 2026

**Qwen 3.8 Max** — 2.4T параметров, 16-дневная автономная способность кодинга
**DeepSeek V4 Pro** — новые рекорды на SWE-bench
**MiMo** — лучшее соотношение SWE-bench score/$ при проксировании; MIT-лицензия делает self-hosting экономически равным по стоимости

### 3. Бесплатные API — масштаб обновился

Репозиторий [awesome-free-llm-apis](https://github.com/open-free-llm-api/awesome-freellm-apis) (обновлён 09.08.2026):
- **424+ бесплатных LLM API от 30 провайдеров**
- Groq — без кредитки, 30 RPM, 14,400 RPD (рекомендуемый старт для новичков)
- Все провайдеры дают OpenAI-compatible endpoint
- One-click конфиги для Claude Code, Cursor, Codex, Aider и 10+ инструментов
- Live-каталог: freellm.net

### 4. Лицензирование open-weight

- **Apache 2.0** — 38% новых релизов на Hugging Face (2026)
- Наиболее благоприятный для коммерческого использования (явное патентное разрешение, отсутствие ограничений)
- Убирает основные барьеры для корпоративных закупок

### 5. Смена приоритетов рынка

- Сдвиг от погони за бенчмарками к **enterprise-оптимизации**: надёжность, комплаенс, эффективность
- **Edge deployability** становится ключевым дифференциатором (MiMo-7B в INT4 = 3.5 ГБ, работает на телефонах)
- Глубокое внедрение AI-агентов в бизнес-процессы, продолжающееся снижение стоимости API

### 6. Стек провайдеров (актуальная карта)

- OpenAI, Anthropic, Google, xAI, Amazon Nova, Mistral — основные коммерческие
- Open-хосты: Together AI, Groq, Fireworks, Hugging Face, DeepInfra
- DeepSeek-V4 Pro — самая дешёвая per-token (июнь 2026)
- OpenRouter — агрегатор с бесплатными моделями (NVIDIA Nemotron Nano 12B VL:free)
