# 🔍 Weekly AI Trends Report — 2026-08-08

## Ключевые находки

### 1. 🚀 OpenAI выпустила первые open-weight модели — gpt-oss (5 августа 2026)

**Серьёзный прорыв:** OpenAI выпустила `gpt-oss-120b` и `gpt-oss-20b` — свои первые open-weight модели за 6 лет (с GPT-2, 2019).

- **gpt-oss-120b** — 120B параметров, мощные reasoning/agentic способности
- **gpt-oss-20b** — 20B параметров, лёгкое локальное развёртывание
- Доступны для скачивания на HuggingFace (collection: openai/gpt-oss)
- Лицензия: open-weight (не full open-source — проверять ограничения)
- Источник: https://openai.com/it-IT/index/introducing-gpt-oss/

**Значимость:** Высокая. OpenAI переходит в open-weight пространство — это меняет ландшафт.

---

### 2. 🤖 Kimi K3 — 2.8 трлн параметров (open weights с 26 июля 2026)

Moonshot AI выпустила Kimi K3 — первую open-source модель с 2.8 трлн параметров (MoE).

- **Архитектура:** MoE, 2.8T params, native MXFP4 ~1.56TB весов
- **Инференс:** vLLM, требует ~16x B200 GPU для full serving
- **Open weights:** доступны с 26 июля 2026
- Конкурирует с закрытыми моделями по архитектуре и enterprise adoption
- Источник: https://www.kimi.com/blog/kimi-k3

**Значимость:** Средняя. Показатель масштаба open-weight тренда, но требует серьёзной инфраструктуры.

### 3. 🌐 Ландшафт бесплатных LLM API (обновление 2026)

- **OmniRoute** — MIT-лицензия, 290+ провайдеров, 90+ бесплатных, 500+ моделей (Kimi, Claude, GPT, Gemini, GLM, DeepSeek, MiniMax)
- **Сравнение 13 бесплатных LLM API 2026** — OpenRouter, Groq, Gemini, Cerebras, Cloudflare. Детальное сравнение лимитов, скорости, контекста, OpenAI-совместимости.
