# AI Trend Report — 2026-08-12 (Update)

## 6. MiniMax H3 — #1 open-weight video model (3 августа 2026)

**Источник:** https://ypyl.github.io/news/2026/08/01/minimax-h3-open-weights-video-model/

MiniMax выпустил **H3** — 33B open-weight модель для генерации видео со звуком.

- Уникальная архитектура: dense Omni-Transformer, обработка видео+аудио как единой задачи
- Вход: текст, изображения, видео, аудио-референсы
- Выход: до 15 секунд, ~768p, синхронизированный стереозвук
- #1 на Video Arena и Artificial Analysis leaderboards для instruction-based editing
- **Лицензия исключает US, EU, UK, Южную Корею** — критичное ограничение

**Impact:** Для VVnetRU — H3 один из лучших open-weight video моделей, но лицензионные ограничения делают его непригодным для коммерческого использования в EU. Стоит мониторить для исследований и демо.

## 7. LTX 2.5 — Real-time open-weight world model (11 августа 2026)

**Источник:** https://venturebeat.com/technology/ltx-2-5-can-generate-a-10-second-ai-video-from-an-image-in-just-6-8-seconds-on-nvidia-superchips-and-its-open-weights

LTX (ex-Lightricks) выпустила **LTX-2.5** — open-weight world model для видео-генерации и физических AI.

- Генерация 10-секундного видео из изображения за **6.8 секунд** на NVIDIA GB200
- Open-weights с day-one ComfyUI поддержкой
- Целевые сценарии: pre-viz в кино, robotics, real-time world generation
- Локальный деплой и дообучение

**Impact:** Единственный open-weight video model без геоблокировки. Подходит для локального деплоя на клиентском GPU. 6.8s/clip — близко к реальному времени. Может быть конкурентом платным облачным решениям.

## 8. NVIDIA Nemotron 3.5 Lightning 30B-A3B (11 августа 2026)

**Источник:** Hugging Face, NVIDIA

NVIDIA выпустила **Nemotron 3.5 Lightning 30B-A3B** — sparse Mixture-of-Experts модель.

- 30B total params, но **активируется только 3B** при инференсе
- BF16 precision, Apache 2.0 (предположительно)
- Unified data pipeline с лицензионно-валидированными данными
- OpenAI-compatible API

**Impact:** Идеальна для локального инференса — 3B activated значит низкое потребление памяти и быстрый инференс на потребительском GPU. Apache 2.0 — свободно для коммерции. Прямой конкурент Muse Glimmer 30B.

## 9. Свободные LLM API: 30+ провайдеров, 474+ моделей (Август 2026)

**Источник:** https://freellm.net/free-llm-api-keys, https://n202.ru/blog/besplatnye-llm-api-2026

Рынок free LLM API вырос до 30+ провайдеров и 474+ моделей.

Топ бесплатных в августе 2026:
- **Groq** — 30 RPM, без кредитки, OpenAI-compatible (Llama, Mixtral)
- **Google AI Studio** — Gemini 2.5 Flash, 1M context, free tier
- **NVIDIA NIM** — instant key, enterprise-grade
- **OpenRouter** — free models (Nemotron Nano), multi-provider
- **Cloudflare Workers AI** — serverless, встроенный в CDN

**Impact:** Для VVnetRU — Groq + Google AI Studio покрывают базовые needs бесплатно. OpenRouter удобен для тестирования нескольких моделей без множества API ключей.
