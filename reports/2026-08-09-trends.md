# AI Trend Report — 2026-08-09

## 1. MiniMax M3 — лидер open-weight рейтинга BenchLM (68.8/100)
**Источник:** https://www.gmicloud.ai/en/blog/ai-model-benchmarks-august-2026-open-weight-models-catch-the-frontier (11 авг 2026)
MiniMax M3 занял #1 среди open-weight моделей по BenchLM. Ключевые характеристики: 1M-токеновое контекстное окно, нативная мультимодальность (текст+изображения+аудио+видео), сильный результат на coding/agentic-задачах. Первая open-weight модель, объединяющая все три фичи.
**Impact:** Сильный кандидат для замены GPT-5.5 в agentic-coding сценариях без зависимости от платных API.

## 2. Grok 4.5 (xAI) — Opus-class модель с API
**Источник:** https://x.ai/news/grok-4-5 (8 июля 2026) | Обновление: https://docs.x.ai/developers/release-notes (5 авг 2026)
xAI выпустила Grok 4.5 как модель уровня Opus для coding, agentic-задач и knowledge work. Доступна через xAI API по цене $2/1M входных токенов и $6/1M выходных. Конфигурируемый reasoning effort (low/medium/high). Интеграция с Cursor на всех тарифах.
**Impact:** Новый конкурент в премиум-сегменте API. Цена конкурентна по сравнению с Claude 5 / GPT-5.5.

## 3. NVIDIA Nemotron 3 Nano Omni — 30B-модел для мульти-агентных AI
**Источник:** https://blogs.nvidia.com/blog/nemotron-3-nano-omni-multimodal-ai-agents/ (28 апр 2026)
Архитектура: 30B-A3B гибридный MoE, Conv3D, EVS, 256K контекст. Объединяет vision, audio, language в одной модели. Лицензия NVIDIA Nemotron Open Model License. Доступен на Hugging Face, OpenRouter и 25+ платформах.
**Impact:** Идеален для self-hosted мульти-модальных агентов на GPU-ПК (наш 172.20.20.15). 3B активные токены = эффективное инференс.
