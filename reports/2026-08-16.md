# AI Trend Report — 2026-08-16

## 1. DeepSeek V4 Pro 0813 — официальный GA-релиз + конкретные повышения цен (13–16 августа)
**Источник:** [ofox.ai](https://ofox.ai/blog/deepseek-v4-pro-0813-price-weights-benchmarks-api-access-2026/), [aireleasetracker.com](https://aireleasetracker.com/model/deepseek/deepseek-v4-pro-0813), [explainx.ai](https://explainx.ai/blog/deepseek-v4-pro-0813-terminal-bench-cline-august-2026), [orcarouter.ai](https://www.orcarouter.ai/blog/deepseek-v4-pro-release-date), [kingy.ai](https://kingy.ai/blog/glm-5-3-vs-kimi-k3-vs-deepseek-v4-pro/), Shazoo (14.08)

**13 августа 2026** DeepSeek вывел `deepseek-v4-pro-0813` из preview в официальный production-релиз. Это — тот самый «V4 Pro», о ценах на который наш 13-й репорт только что писал, что DeepSeek «expects to raise overall API prices significantly». Теперь цифры конкретные и применимы уже **с 16 августа 19:00 мск**:

- **Terminal-Bench 2.1: 87.9** — рекорд для V4-линии. При сравнении: V4-Flash-0731 = 82.7, апрельский V4-Pro-Preview = 72.1. Рост почти на *5x* по сравнению с preview (DeepSWE leap).
- **CyberGym: 83.3** — высший показатель в лабораторной сверке DeepSeek на момент запуска.
- **Фичи GA**: нативная поддержка OpenAI Responses API, image input, one-click Codex setup, переключатель low/high/max reasoning control.
- **Конкретика повышения цен** (новость 14 авг, действует с 16 авг 19:00 мск):
  - *Пиковые часы*: input — **0.025 → 0.30 RMB/млн токенов (12×)**, output — **0.87 → 3.96 USD/млн токенов** (~4.6×).
  - *Непиковые часы*: в 2× дешевле пиковых (в 6× дороже старых тарифов).
  - Введена система **peak/off-peak time-of-day pricing** для распределения ресурсов. OpenRouter, DeepInfra и прочие реселлеры округляют цену сами — DeepInfra/$2.67 и pricepertoken $0.279/$0.557 уже могут устаревать.

**Impact:** Наш 13-й репорт советовал «закрепиться за текущими low-per-token тарифами до повышения». Цена повышена — поздновата для V4 Pro. V4 Pro становится frontier MoE, но с уже не low-cost. DeepSeek V4 Flash 0731 + V4 Pro 0813 теперь unified Responses API = реальная альтернатива Claude для coding-агентов. Добавить в OmniRoute candidate pool, но с учётом новых peak/off-peak цен (route Flash в часы пик).

## 2. Qwen3.8 generation — 2.4T MoE, но лицензия ограничена (сентябрь/август 2026)
**Источник:** [Hugging Face Qwen/Qwen3.8-2.4T-A95B](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B), [explainx.ai](https://www.explainx.ai/blog/qwen3-8-max-open-weights-live-hugging-face-august-2026), [xenospectrum.com](https://xenospectrum.com/en/qwen38-open-weight-licenses/), [openlm.ai](https://openlm.ai/qwen3.8/)

Alibaba открыла веса **Qwen3.8-Max** — первая в истории Max-класс модель с открытыми весами:
- **Qwen3.8-2.4T-A95B** — 2.4 трлн параметров, MoE, 95B активных экспертов, контекст **1M токенов**.
- Заявлено: лидирует Frontend Code Arena, обгоняет ChatGPT-5.6 Sol и Claude на ряде бенчмарков.
- ⚠️ **Лицензионный повод для бдительства**: веса на HF (2.4T-A95B) вышли **не Apache 2.0**, а по новой **Qwen3.8-Max License** — revenue-share/коммерческая лицензия с ограничениями (relisted as «stripped, relicensed, half-delivered», text-only, без 1M context в релизе-версии).
- **Qwen3.8-27B** — dense, vision input, **Apache 2.0**. Это чистый/одиночный вариант, пригодный для self-hosted на GPU-ПК. Unsloth уже выложил GGUF-кванты (unsloth/Qwen3.8-27B-GGUF, NVFP4) и Desktop-поддержку.

**Impact:** Qwen3.8-Max — очередной frontier MoE, но с ограниченной коммерческой лицензией (наравне с ограничениями Kimi/K2.5). Для VVnetRU: Qwen3.8-27B Apache 2.0 — безопасный self-hosted кандидат; Qwen3.8-2.4T-A95B — только research/не-commercial пока. Добавить Qwen3.8-27B в OmniRoute candidate pool.

## 3. Meta Muse Glimmer 30B — возвращение Meta на open weights (10 августа)
**Источник:** [Hugging Face unsloth/Muse-Glimmer-30B](https://huggingface.co/unsloth/Muse-Glimmer-30B), [newsanalysis.net](https://newsanalysis.net/meta-muse-glimmer-open-agent-single-gpu/), officechai.com, ccleaks.com

Meta **10 августа 2026** вернулась к open weights после закрытого Muse Code:
- **Muse Glimmer 30B** — плотная (dense) модель ~29.6B параметров, **Apache 2.0**, веса на HF (~59.6 GB BF16, 13 shards).
- Спроектирована для **always-on local агентов на одной consumer GPU / Mac** (single GPU inference).
- Заявлено: обходит Gemma 4 31B Google на большинстве бенчмарков; ориентирована на reliability требований автономных агентов.
- Также объявлено, что весы **Muse Spark 1.2** (флагманская) тоже станут open source — первый шаг Meta обратно в open-weights ландшафт, где она давно отстаивала.

**Impact:** Glimmer 30B — лакомый кусочец: Apache 2.0 + 30B + single-GPU. Прямой конкурент Kimi K2.7 Code / Qwen3.8-27B в нише self-hosted coding agents. Скачать и протестировать на GPU-ПК (172.20.20.15, single-GPU развёртывание).
