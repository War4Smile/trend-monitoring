# Trend Monitoring

Ежедневные отчёты по трендам AI/LLM рынка.
Отчёты хранятся в папке [reports/](reports/) в формате MD.

## Структура
-  — отчёт за день
-  — ежемесячная сводка

## Параметры мониторинга
- Open-weight модели
- Бесплатные API провайдеры
- AI инструменты для бизнеса
- Кейсы внедрения AI
- Лицензии open-weight моделей
